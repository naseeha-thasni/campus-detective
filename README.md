### Project Description
campus detective is a web app that helps students report lost and found items on campus. Users can quickly post items, claim them, and earn reward points
### The Problem statement
Students often lose personal items on campus, and there’s no centralized way to report and retrieve them efficiently.
### The Solution
Our system allows users to post lost or found items, view available items in a feed, and claim ownership. A reward system encourages honest reporting.
